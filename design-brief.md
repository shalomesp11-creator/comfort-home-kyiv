# COMFORT HOME restoration brief

Design read: A Ukrainian full-cycle renovation studio for homeowners who need calm confidence, material quality, and a clearly managed process.

Concept spine: Architectural dossier. The site reads like a finished project book: numbered sections, drawing references, material photography, ruled dividers, and restrained editorial typography.

Delivery tier: editorial. The public original uses light interaction, an opening image zoom, hover crop motion, marquee movement, and scroll reveals rather than a cinematic camera journey.

Animation mode: non-animated — user explicitly requested the animations of the existing public version to be preserved as closely as possible, not replaced by a new scroll-scrub experience.

Tier-1 technique: D3 kinetic type opener, re-expressed as the original hero image zoom plus a mounted editorial headline reveal. Supporting motion is limited to existing-style section reveals, hover image scaling, menu transitions, and the services marquee.

Brand constraints: Restore the existing public COMFORT HOME identity exactly. Use the public logo, original photography, original video, original Manrope and Instrument Serif font files, and the site’s own visible copy.

Locked palette: Ivory #FAF5ED, graphite #211D1A, graphite-soft #403C39, champagne #C7A475, champagne-soft #D5C1A4, beige #EFE7DB, border #DDD7CD, muted #5D5751. This otherwise restricted beige/brass family is mandatory because it is the owner’s existing public brand.

Locked type: Manrope variable for body and interface; Instrument Serif for display, numbers, and italic emphasis. The serif pairing is brand-authentic and directly recovered from the original CSS.

Corner language: Mostly sharp architectural rectangles and hairline borders. Only the video stage and lead modal may use a restrained 8 to 12px radius where the original already signals softness.

Reference system: The six live public pages are the authoritative visual boards. Captured desktop and mobile references belong in refs/original-*.png. Source HTML snapshots are diagnostic only and remain outside the product.

Home section plan: full-bleed image-first hero; split studio story with four metrics; three service image cards; asymmetric portfolio grid; full-width dark video stage; testimonial rail; dark numbered process list; split architecture checklist and image; large invitation band; global footer.

Repairs page plan: full-bleed service hero; numbered scope list; split design-method feature; dark calculation band; global invitation; footer.

Construction page plan: full-bleed service hero; editorial approach split; three-image strip; nine-item scope grid; four-reason ruled list; dark project invitation; global invitation; footer.

Design page plan: full-bleed service hero; two-image gallery; numbered deliverables; image-led realization feature; dark conversion band; global invitation; footer.

Portfolio page plan: full-bleed hero; accessible category filter rail; responsive masonry-style project grid; global invitation; footer.

Contacts page plan: editorial contact hero; three direct contact blocks; no embedded long form; messenger links and company record; global invitation; footer. Every lead CTA opens the shared modal.

Asset plan: 19 original interior photographs; one locally stored client video; recovered public logo; exact local font files; code-native brand mark used where the original draws it as SVG; hero image reused for social cover without external dependencies.

Head kit: favicon and touch icons derived from the public logo; site.webmanifest; branded OG image; per-route title, description, canonical URL, and social metadata; Organization, WebSite, and ProfessionalService JSON-LD on the homepage.

CTA inventory: header consultation outline; hero champagne project trigger; portfolio ghost link; service card whole-surface links; work-grid links; dark estimate band trigger; text-arrow detail links; global invitation trigger; contact phone and messenger links. All consultation, application, booking, estimate, and project-discussion intents open the one lead modal.

Lead modal: Name, phone, service type, comment. Telegram submission is intentionally deferred. A prepared submit adapter boundary remains explicit; the current submit confirms readiness without transmitting personal data.

Responsive contract: desktop uses the original 1400px content rail and 12-column layouts; tablet collapses complex splits; mobile uses a full-height right drawer, single-column sections, horizontal filter scrolling, touch-sized controls, and crop positions tuned per source image.

Accessibility: keyboard-operable menu, modal focus management and Escape close, visible focus states, explicit labels, required phone field, semantic headings, alt text, reduced-motion fallbacks, and sufficient contrast.

Anti-convergence ledger: No previous build exists in this chat. The six axes are inherited from the owner’s public site: ivory/champagne palette, Manrope plus Instrument Serif, image-first full-bleed hero, D3 editorial opener, sharp architectural CTA garments, and ruled rectangular chrome.
